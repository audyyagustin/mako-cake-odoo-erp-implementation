
# Project Overview – MAKO Cake and Bakery

## Project Background

MAKO Cake and Bakery is an academic group project developed as part of the Integrasi dan Kustomisasi ERP course at Universitas Esa Unggul.

The project focuses on implementing Odoo 18 as an integrated Enterprise Resource Planning (ERP) system to support the business operations of a simulated bakery company.

The implementation translates business process models into Odoo workflows through module configuration, master data preparation, transaction simulation, and system testing.

## Implementation Approach

The project follows several implementation activities:

1. Business process analysis and modeling.
2. Mapping business processes to Odoo modules.
3. System configuration and master data preparation.
4. Business transaction simulation.
5. Module-level testing and process evaluation.
6. Project documentation.
